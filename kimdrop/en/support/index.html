HERE TO HELP

A little help,
when you need it.

Start with your Wi-Fi network, the current address and app permissions. Find answers below.

The browser cannot open the address.

Connect both devices to the same Wi-Fi, allow Local Network access for KimDrop in iOS Settings, and keep the app in the foreground. Use the complete http:// address and port shown in the app. Guest networks, client isolation, VPNs or firewalls may block local connections. Network changes can change the address.

My access code expired or I was signed out.

Restarting sharing generates a new random code. Automatic locking, session revocation or expiry can also end authorization. Enter the current code displayed on iPhone. After repeated incorrect attempts, wait for the indicated retry period.

Some photos are missing.

Check Photos access in KimDrop Settings. With limited permission, only selected photos are available. Adjust the selection in iOS Settings if needed. Originals stored only in iCloud may need an internet connection for Apple Photos to retrieve them. Denying Photos access does not prevent app-file transfers.

Upload or delete controls are unavailable.

Check browser read-only, app-file write and photo-deletion permissions in Settings. Photo deletion also requires confirmation on iPhone. These settings restrict browser actions, not local actions inside the iPhone app.

Transfers stopped in the background.

iOS may suspend background apps. Keep KimDrop in the foreground until the task finishes. When you return, check the result and retry incomplete transfers as needed.

A document or video will not open.

A file that can be transferred may not be previewable. Playback and preview depend on format, codec, file integrity and system support. Use the system share menu to open it in another installed app. RAR support is for extraction, not RAR creation.

How do I disconnect or remove data?

Tap Stop Sharing to end current browser sessions, or manage sessions in Settings. Delete app files to remove their local copies. Photo deletion requires system confirmation. Downloads already saved on a computer must be removed there. Clear browser site data to remove local browser storage and caches.

Do I need an account, subscription or desktop app?

No KimDrop account or desktop installation is required. The app has no subscriptions or in-app purchases. Availability and price will be shown on its App Store page when released.
