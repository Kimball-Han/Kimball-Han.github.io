Kim Games Support

Kim Games 1.2.0 includes 17 games for iPhone and iPad. Most games work offline. Go, Chinese Chess, Chess, Baifang, and Gomoku offer optional Apple Game Center matches. The five board games include move sounds, clearer turn indicators, and victory celebrations.

Quick fixes

  • Update iOS and Kim Games to the latest available versions.
  • If a game stops responding, return to the lobby and open it again. If needed, fully close and relaunch the app.
  • For online play, confirm that you are signed in under Settings › Game Center and that your network connection is available.
  • Some games use landscape orientation. Rotation lock can prevent the expected layout change.

Board-game sounds and celebrations

If board-game sounds are muted, check the in-game sound setting, device volume, silent mode, and current audio output. Reduce Motion simplifies the visual celebration; it does not replace the sound toggle.

Contact the developer
Kimball · bovvge@gmail.com
Please include your device model, iOS version, game name, and a short description of the issue. We usually respond within seven days.

Kim Games 技术支持

Kim Games 1.2.0 为 iPhone 与 iPad 提供 17 款游戏。大多数游戏可离线游玩；围棋、中国象棋、国际象棋、摆方和五子棋可通过 Apple Game Center 进行在线对战。五款棋类支持落子音效、更醒目的回合提示和胜利庆祝。

常见问题排查

  • 请将 iOS 与 Kim Games 更新到当前可用的最新版本。
  • 如果游戏停止响应，请返回游戏大厅后重新进入；必要时完全关闭并重启 App。
  • 在线对战前，请在“设置 › Game Center”中确认已登录，并检查网络连接。
  • 部分游戏使用横屏。开启方向锁定可能阻止界面正常旋转。

棋类音效与胜利庆祝

如果听不到棋类音效，请检查游戏内声音设置、设备音量、静音模式和当前音频输出。减少动态效果会简化视觉庆祝，不等同于声音开关。

来信时请附上设备型号、iOS 版本、游戏名称和问题描述。通常会在 7 天内回复。

Kim Games 技術支援

Kim Games 1.2.0 為 iPhone 與 iPad 提供 17 款遊戲。大多數遊戲可離線遊玩；圍棋、中國象棋、國際象棋、擺方和五子棋可透過 Apple Game Center 進行線上對戰。五款棋類支援落子音效、更醒目的回合提示和勝利慶祝。

常見問題排解

  • 請將 iOS 與 Kim Games 更新至目前可用的最新版本。
  • 如果遊戲停止回應，請返回遊戲大廳後重新進入；必要時完全關閉並重新啟動 App。
  • 線上對戰前，請在「設定 › Game Center」中確認已登入，並檢查網路連線。
  • 部分遊戲使用橫向顯示。開啟方向鎖定可能阻止介面正常旋轉。

棋類音效與勝利慶祝

如果聽不到棋類音效，請檢查遊戲內聲音設定、裝置音量、靜音模式和目前音訊輸出。減少動態效果會簡化視覺慶祝，不等同於聲音開關。
